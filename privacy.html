Privacy Policy – GTA6 Clipper

Last updated: November 20, 2026

GTA6 Clipper is a personal desktop tool operated by Aleksey Paltis. It is used only by its operator to upload videos to his own YouTube channel.

Data accessed

With your permission (Google OAuth), the tool uses the YouTube Data API to upload videos and to read the name of the authorized channel (scopes: youtube.upload, youtube.readonly). It does not access any other Google data.

Storage

The OAuth access token is stored only locally on the operator's computer. No data is sent to any server other than Google/YouTube, and no data is sold or shared with third parties.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
