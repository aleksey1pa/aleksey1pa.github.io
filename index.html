GTA6 Clipper

GTA6 Clipper is a private tool run by Aleksey Paltis on his own computer. It cuts short gameplay clips into vertical videos and uploads them to Aleksey's own YouTube channel via the YouTube Data API.

GTA6 Clipper ist ein privates Werkzeug von Aleksey Paltis, das auf seinem eigenen Computer läuft. Es schneidet kurze Gameplay-Clips ins Hochformat und lädt sie über die YouTube Data API auf Alekseys eigenen YouTube-Kanal hoch.
